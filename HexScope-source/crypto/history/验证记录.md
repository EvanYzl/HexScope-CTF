# 密码增强模块验证记录

验证对象：独立模块 1.0、生成的单文件 HTML，以及基于发布版 4.0 的便携副本。未测试或改动主线程正在开发的挂载/哈希功能。

## 自动化验证

197 项测试全部通过：96 项算法测试、90 项任务入口/示例测试、11 项界面操作测试。完整输出在 `tests/验证结果.log`。

- Base 编码已知向量、前导零、中文与补充平面 Unicode、非法格式拒绝。
- 古典密码公开向量、矩阵可逆性、带重复关键词的列移位、往返和错误参数。
- 摘要与 HMAC/PBKDF2 对照 Node/OpenSSL；MD4、RIPEMD、ChaCha20、Ed25519 等公开向量。
- AES 各模式与认证标签、DES/3DES/IDEA/Blowfish/Twofish、RC4、A5/1、Salsa20；Blowfish 包含非 4 字节倍数密钥的独立 OpenSSL 对照。
- RSA 多种攻击、OAEP/签名、回代校验、CRT、ECC BSGS/PH/Smart、Coppersmith、LLL、DSA、DH、ElGamal、LCG、Shamir。
- 长度扩展的分组边界、加盐字典、S-box DDT/LAT、合成 CPA、截断生日碰撞。
- 多层 Base64、Base64+Caesar、Base64+二进制 XOR、Base91、Bacon、GZIP、旧版佛曰的自动恢复；预算约束。
- 78 个可见工具入口的示例均实际执行，RSA/OAEP、CPA 等不再使用报错占位数据。
- 单文件 HTML 中的真实 Worker 脚本经 Node Worker 执行；DOM 中测试候选、路径、下载、JSON 报告、文件分析队列桥接、取消、输入变更、异步文件读取失效处理。
- 输入中的 HTML/JavaScript 不会被作为标签或脚本执行；JWT 算法白名单、验签失败、错误参数与空字符串哈希得到相应结果。

## 测试边界

界面测试使用 jsdom 和真实后台计算线程，未验证桌面实际渲染、缩放后的视觉布局、系统文件选择器、操作系统拖拽及真实用户机器的兼容性。不能把 DOM 测试称为人工 GUI 验收。

便携版沿用原发行包的 Electron 与取证组件；本次只校验复制文件、入口配置、嵌入的增强 HTML 和压缩包完整性，没有重新运行真实 E01 镜像流程。

高级密码算法使用公开向量、独立实现对照或可回代的测试参数；这不构成密码库的独立安全审计。自动候选分、统计密钥与 CPA 相关性均不能表示正确率。

## 已修复的集成问题

- 八位 `\\U0001F600` 的 Unicode 转义归一化。
- 构建时字符串替换对压缩库内 `$` 特殊序列的破坏。
- 不规则长度的 Blowfish 密钥，按字节周期展开为 P 数组所需的 72 字节材料。
- 文件异步读取后覆盖已编辑内容、古典密码回填为错误 Hex 文本的问题。
- 非 RSA 的花括号文本被错误终止为 RSA 参数错误的问题。

源代码与固定依赖锁文件随包提供，方便复核和继续扩展。
