    如何理解结果
    结构通过：已根据容器结构确定边界。ZIP 压缩成员的内容 CRC 在解压时校验；结构通过不代表不存在其他损坏，也不证明有人故意隐藏。
    元数据 / 内嵌：可能为 EXIF 缩略图等合法内容，默认不选入批量导出。
    仅签名：不能确认完整性和结束位置，导出为 .bin；可手工调整区间。
    未见异常：批量队列仅检查文件结构。EXIF、字符串、像素与 LSB 在相应标签页单独运行；未运行不表示未检出。不覆盖 JPEG DCT、碎片重组、密码破解或所有文件格式。
    

    取证镜像（桌面版）
    打开 E01 首卷或 DD / RAW 镜像，按分区浏览目录树、筛选大小、提取文件或送入隐写分析。分卷须保持完整和原始命名。选择目录导出会递归提取，结果含原路径、inode、时间字段和 SHA-256 清单。镜像按需读取，不受普通文件 128 MiB 限制；送入隐写分析的单个文件仍受此限制。镜像引擎仅在 Windows 便携版可用。
    哈希、推送与盘符（4.1）
    「哈希校验」支持本机文件；镜像工作台可计算解码后的完整源盘数据及镜像内单个文件。支持 12 种算法、HEX / Base64 表示、预期值比对、TXT / JSON 导出。镜像内文件或目录可以一键送入文件分析；跳过和失败内容有推送清单。
    E01 可先转固定 VHD，再用 Windows 自带功能选择分区、盘符并只读挂载。转换需要接近源盘容量的空间；挂载和卸载请求管理员授权。固定 VHD 限 512 字节逻辑扇区、2040 GiB；资源管理器仅支持 Windows 可读文件系统。关闭软件不会自动卸载。
    文件预览
    选择文件后打开「文件预览」：DOCX 正文、表格和内嵌图片；Excel / CSV 工作表、分页与搜索；PDF 翻页与缩放；图片旋转与缩放，以及文本、部分音视频和 ZIP 目录。镜像送入的文件也可预览。全部离线，只读显示；Office 上限 32 MiB、PDF 64 MiB，表格限前 2,000 行 / 100 列。格式覆盖与限制见随包文件预览说明.md。
    密码分析（78 个工具入口）
    自动分析支持有限预算的多层编码、部分古典密码、压缩和 XOR 尝试，显示候选排序、转换路径和停止原因。题型工具提供古典密码、现代密码、RSA / ECC、签名、哈希及数论等参数化运算。计算在本机 Worker 运行，可以停止、导出报告或把恢复字节送入文件分析。
    候选分不是正确率，未命中不表示无解；现代密码一般需要密钥，侧信道和高级题型需要样本或额外条件。自动输入上限 32 KiB、8 层，单任务总上限 40 秒。完整适用范围见密码分析内的「覆盖范围」与随附题型说明。
    CTF 工具
    EXIF / GPS 标签页支持元数据搜索、原始标签值、经纬度及 JSON 导出。文件树可以按 B / KiB / MiB 大小区间筛选和排序。字符串标签页可定位偏移并将文本送到编码工作台。
    像素 / LSB 支持 8 位非交错 PNG、24/32 位未压缩 BMP。可查看位平面、选择通道与读取顺序、扫描 32 种常见 LSB 组合、导出并继续分析提取结果。不能覆盖所有隐写方式。
    专项隐写
    新增 ZIP 伪加密验证与副本修复、PNG CRC / 宽高恢复与调色板低位、零宽字符 / 空格 Tab / Base64 填充位、整数 PCM WAV 波形 / 频谱 / LSB / DTMF / 倒放与声道差、双图 XOR / 差异 / RGB 奇偶 / 边框，以及 GIF / APNG 原始局部帧导出。专项工具需手动运行，结果可保存、加入队列继续分析或导出报告。
    WAV 每段分析最长 120 秒，支持 8/16/24/32 位整数 PCM；动图最多 1,000 帧，不合成前帧；PNG 宽高恢复验证非交错扫描行。真实加密、JPEG DCT、音频压缩格式和特定隐写工具算法不在这些模块范围内。
    范围与限制
    边界解析：PNG、JPEG、GIF、WebP、BMP、普通单卷 ZIP、7z。RAR、PDF、GZIP 候选仅签名提示。ZIP64、多卷 ZIP 不做可靠提取。
    文件队列不设条目数量上限，按页显示全部条目；分析默认按逻辑处理器数并行，活动数据量过大时自动排队。单文件 128 MiB，批量导出 256 MiB，ZIP 解压单成员 32 MiB、合计 128 MiB，像素分析上限约 8 百万像素。超过限制会明确提示。
    开源组件：exifr 7.1.3（MIT），fflate 0.8.3（MIT），均内置在此文件中，许可见源码包 vendor 目录。专有 MakerNote 不保证可解释，EXIF 时间不擅自转换时区，GPS 来自元数据而非实际位置验证。
    推荐使用新版 Edge / Chrome。应用不联网、不上传、不自动打开导出的文件。刷新或关闭页面会清空内存中的队列，请及时导出报告。
