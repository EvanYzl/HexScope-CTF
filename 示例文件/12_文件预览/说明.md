# 文件预览示例

拖入此目录的文件，在文件分析中选择一项，点击「文件预览」。

- sample.docx：中文、表格与内嵌图片。包含作为文字显示的 HTML 线索。
- sample.xlsx：数字格式、公式、隐藏行列、隐藏工作表，以及超过预览行列上限的内容。
- sample.xls / sample.xlsb / sample.ods：其他表格容器。
- sample.csv：中文与带逗号的引用字段；不执行公式。
- sample.pdf：两页文字，第二页旋转 90 度。
- encrypted.pdf：相同的两页 PDF，打开密码为 **hexscope**。
- gbk.txt / utf16.txt：两种常见中文文本编码。
- pixel.png：2 × 2 像素的半透明 PNG。

这些样本均为程序生成的演示数据，不包含真实用户文件。完整限制见「文件预览说明.md」。
